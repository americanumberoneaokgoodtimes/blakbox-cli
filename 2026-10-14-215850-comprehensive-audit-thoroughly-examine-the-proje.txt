  rotation cycle. Triggered when max_recordings files have been created.

  High

  - BUG-03: Total bytes displayed is raw PCM input to ffmpeg, not compressed
  output — shows 4–8× inflated numbers.
  - BUG-04: Clipping counter accumulates across automatic file rotations, making
   it meaningless.
  - BUG-05: Unix/macOS keyboard input is non-functional — all controls
  (Q/N/+/-/A/R/B) require pressing Enter due to terminal not being in raw mode.
  - BUG-06: Edge case double-launch of ffmpeg when N-key coincides with
  automatic rotation.
  - BUG-07: Elapsed timer resets inconsistently (resets on N/Rename but not on
  auto-rotation).
  - BUG-08: No ffmpeg availability check at startup — compressed-format users
  get a silent crash.

  Medium / Low / Architecture

  - Silent ffmpeg crash with no HUD notification
  - FLAC size estimation is inaccurate (hardcoded 0.55 ratio)
  - No gain reset shortcut
  - Final output path not displayed when recording ends
  - blakbox1.0.py legacy file pollutes the repo
  - Boss Mode B/b case-sensitivity undocumented
  - No --version flag, no config persistence, no pre-flight device test
